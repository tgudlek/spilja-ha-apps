# Spilja add-ons

Home Assistant add-ons.

| Add-on | What it does |
|---|---|
| [Claude Code](claude_code/DOCS.md) | An always-on Claude Code session on the Home Assistant machine, in the sidebar and in the Claude app through Remote Control |

To install, add this repository in Home Assistant: **Settings → Add-ons →
Add-on store → ⋮ → Repositories**, then paste
`https://github.com/tgudlek/spilja-ha-apps`.

Read the add-on's [security notes](claude_code/DOCS.md#security) first: it can
change your configuration and reach your Home Assistant API.
